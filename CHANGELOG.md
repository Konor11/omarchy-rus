# Список изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).
Новые изменения копятся в разделе «Не выпущено», перед выпуском он переименовывается в номер версии с датой: `## [1.4.0] — 2026-10-10`.
Релиз по тегу берёт текст этого раздела в описание релиза и не собирается, если раздела для тега нет.

## [Не выпущено] — 2.0.0

### Добавлено
- Модуль `language`: `omarchy language ru` — установка русского языка интерфейса через нативную
  i18n Omarchy (локаль, LANG, язык шелла/меню/клавиш/уведомлений).
- Модуль `emoji-ru`: русские ключевые слова для поиска эмодзи (`merge-emoji-ru.py`).
- `uninstall.sh`: полный откат установки — удаляет клоны плагинов, расширение меню, обёртки
  горячих клавиш, хук post-update, DNS-хелпер, конфиг fastfetch, сертификаты Минцифры.
  Флаги `--dry-run` и `--purge` (снос пакетов, локали, раскладки).

### Удалено
- `translate-menu.py`, `translate-plugins.py`, `keybindings-ru.py`, `check-i18n.py` —
  Omarchy >= 3.8 имеет нативную i18n с полным русским языковым пакетом
  (`default/i18n/ru/`: menu.json, shell.json, keybindings.json, cli.json).
- Модули `panels`, `menu`, `keybindings`, `post-update-hook` — заменены нативной i18n.
- `data/notifications-ru.json`, `data/i18n-ignore.txt`, `input.lua.snippet` — больше не нужны.
- Модуль `locale` — объединён с `language` (`omarchy language ru` + `localectl`).

### Изменено
- Модуль `weather`: упрощён — только `unit=metric` в shell.json и патч геокодинга
  (`language=en` → `language=ru`). UI-строки переводятся нативной i18n.
- Модуль `dns`: оставлен без изменений — клон сетевого виджета и `omarchy-dns-ru`
  единственный оправданный клон плагина (провайдеры захардкожены в QML).

### Миграция с 1.x
Если установлена версия 1.x — сначала откатите её:
```bash
./uninstall.sh            # удалить артефакты перевода (клоны, меню, горячие клавиши)
./uninstall.sh --dry-run  # посмотреть, что будет удалено
```
Затем установите новую версию:
```bash
./install.sh
```

## [1.3.0] — 2026-10-02

### Добавлено
- Перевод подсказки индикатора напоминаний («Создать напоминание», «N напоминаний»).
- Переводы Dropbox, Agents, виджетов бара (индикаторы, микрофон, обновления, трей), меню Tmux и Herdr.
- Поиск эмодзи по-русски (названия CLDR, `data/emojis-ru.json`, 1870 записей).
- Хук после обновления пересобирает и меню Tmux/Herdr.

### Исправлено
- `grep -F` с маркерами, начинающимися с дефиса, в модулях 15, 16, 17, 68 и 85.

## [1.2.0] — 2026-09-30

### Добавлено
- Необязательный модуль `post-update-hook`: после `omarchy update` заново собирает русские меню.

## [1.1.0] — 2026-09-30

### Добавлено
- Необязательные модули тачпада: натуральная прокрутка и жест тремя пальцами для смены рабочих столов.
- Скриншот в README.

### Изменено
- CI переведён на действия под Node 24 (checkout/upload-artifact v7), раннер закреплён на ubuntu-24.04.

## [1.0.0] — 2026-09-30

### Добавлено
- Первый выпуск: модульный установщик русификации Omarchy (локаль, раскладка, орфография, часовой пояс, Compose,
  шрифт TTY, LibreOffice, Telegram, погода, перевод панелей и меню, voxtype, TTS, fastfetch, ЭЦП).
- Модуль `dns`: российские DNS-провайдеры в виджете сети.
- Модуль `keybindings`: русское меню Super+K.
- Релиз по тегу, пошаговая инструкция по установке.
